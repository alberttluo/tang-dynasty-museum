# Image credits

Every image here comes from Wikimedia Commons and its licence was read from the
Commons API (`extmetadata`) at the moment of download, not from memory. Only files
reported as `Public domain`, `CC0`, or `PD-*` were accepted; `CC BY` and `CC BY-SA`
files were rejected so that this credit format never carries an unmet attribution
requirement.

Commons servers are not hotlinked. These are committed local copies.
